# Cookwise — Step-by-Step Recipe Guide

Cookwise is a responsive cooking companion for everyday home meals. Choose a dish and follow clear instructions that explain what to add, when to add it, why the step matters, and what to look for as it cooks.

## Features

- Search recipes by dish or ingredient
- Filter by breakfast, quick meals, comfort food, and snacks
- See prep time, cook time, difficulty, and serving size
- Scale ingredient quantities for 1–8 servings
- Check off ingredients while you get ready
- Follow every step with an “add now,” “why,” and “look for” explanation
- Open Cook Mode for one-step-at-a-time directions
- Use the optional step timer
- Save favorite recipes in this browser
- Responsive layout for phone, tablet, and desktop

## Recipes included

Masala Poha, Vegetable Upma, South Indian Lemon Rice, Everyday Dal Tadka, Quick Chana Masala, Paneer Butter Masala, One-Pot Vegetable Pulao, Aloo Gobi, Tomato & Basil Soup, and Besan Chilla.

## Run it locally

Open `index.html` in a modern browser. No installation, account, API key, server, or build step is required.

## Files

- `index.html` — page structure
- `styles.css` — responsive visual design
- `app.js` — recipes, search, serving scaling, saved favorites, and Cook Mode
- `favicon.svg` — Cookwise icon

## Privacy and food notes

Saved favorites stay in this browser's local storage. Cookwise does not send recipe or personal data to a server. Quantities and cooking times are home-kitchen estimates; adjust seasoning to taste and check ingredient labels for allergens.
